# Product design

- Users: AI architects and workshop participants discovering and reviewing use cases.
- Problem: the existing generated scatter chart cannot be freely edited or shared across browsers.
- Scope: a standalone node-and-connection board; card editing, dragging, scoring, search, import/export, live updates, and JSON data inside this repository.
- Success: an edit survives browser reload and server restart; two browsers connected to the same server receive the same saved graph.
- Publication: show the saved board at the user's exact Phase 1 GitHub Pages URL and keep the existing workflow workshop accessible.
- Non-goals: automated AI evaluation, invented workshop content, cloud provisioning, public anonymous editing, or automatic Git commits/pushes.
